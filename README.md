# 🧬 BME160: Research Programming in the Life Sciences

## 📖 Course Description

This repository contains code and resources for **BME160**, a course at UC Santa Cruz focused on teaching Python programming within the context of life sciences and bioinformatics.

Students gain hands-on experience with:
- Python fundamentals (classes, functions, string manipulation)
- Biological data parsing and analysis (FASTA, amino acids, codons)
- Jupyter Notebook workflows and markdown documentation
- Custom algorithm development (e.g., ORF finders, ProtParam replicates)
- Collaborative coding, code inspections, and team projects

The course emphasizes real-world problem solving and includes a **final project** where students apply programming to investigate a biological question.

### 🛠 Tools & Libraries
- Python 3.13+
- Jupyter Notebook
- Biopython, NumPy
- Git & GitHub

Each directory in this repo corresponds to a lab, assignment, or project component. Sample input files and instructions are provided where relevant.
